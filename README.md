# Twist & Bake — React website

A multipage React (Vite + React Router) website for Twist & Bake, a Hungarian chimney cake (kürtőskalács) bakery on Bristol Road, Selly Oak, Birmingham. The theme follows the Twist & Bake logo (chocolate brown, caramel gold and cream).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`. This is a single-page app, so the host must serve `index.html` for every route (`vercel.json` and a Netlify `public/_redirects` file are included).

## Pages

Home, Menu (with category filter), Our Story, Visit Us, 404.

## Notes

Concept website. The logo and photos belong to Twist & Bake; get their permission before using this as their live site. Menu prices are not published online, so none are shown.
